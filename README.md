# TEE / TDX / SGX Atlas

A bilingual, security-first learning site for engineers familiar with x86 and virtualization. The English edition is the default; visitors can switch to Chinese, and the preference is shared with the other ShundaZhang learning sites on the same GitHub Pages origin.

The site is static HTML, CSS and JavaScript. Run `python3 build.py` to rebuild the eight pages. The browser-only policy lab is illustrative: it does not produce or verify hardware attestation evidence.

Published at <https://shundazhang.github.io/tee-tdx-sgx/>. Primary documentation is linked on the Labs & sources page. Content last checked on September 30, 2026.
